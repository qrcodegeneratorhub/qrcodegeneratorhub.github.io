QR Code Size and Print Quality: How Big Is Big Enough?

A QR code that is too small, too faint or too damaged will not scan. The sizing and printing rules that guarantee a first-time scan.

A QR code is a precise pattern, and printing it badly is the most common reason it fails. A code that looks fine on a screen can be unscannable on paper because it is too small, printed at low resolution, low contrast, or distorted by the printing process. The rules for size and print quality are simple and well tested, and following them costs nothing. This guide gives you the numbers: how big a code must be for each viewing distance, what resolution to print at, and how to check a print before you commit to a thousand copies.

The size rule: distance decides

The size of a QR code is dictated by the distance from which it will be scanned. A useful rule is that the code should be at least one tenth as wide as the scanning distance: scan from 30 centimetres and the code should be at least 3 centimetres wide; scan from 3 metres and it should be at least 30 centimetres wide. For a business card or a receipt scanned at arm's length, 2 centimetres is the practical minimum. For a poster scanned from across a room, 10 centimetres or more is needed. For a billboard, the code must be measured in metres. When in doubt, go bigger: a code that is too large still scans, while a code that is too small does not scan at all.

Resolution: print sharp, not blurry

A QR code is made of small square modules, and each module must print sharply. Download the code at the highest resolution available — our generator produces a 1024 by 1024 pixel PNG — and print it at 300 dots per inch or better. A code downloaded as a small image and enlarged will blur, and a blurred code fails because the scanner cannot tell where one module ends and the next begins. Never copy a code from a screenshot, never stretch it, and never let a designer resize it by dragging a corner in a way that distorts the proportions. If the code must be printed very large, ask for a vector version or regenerate it at a higher resolution.

Contrast and colour: dark on light wins

Scanners read QR codes by contrast, and the most reliable combination is black modules on a white background. Coloured codes can work, but only when the contrast stays strong: dark blue on white is usually fine, light grey on white is not, and a code printed over a photograph or a gradient is risky. Inverted codes — light modules on a dark background — fail on many scanners, so avoid them. If your brand colours are light, keep the code itself black and use the brand colours around it, not in it. Test any coloured code on two different phones before printing, because a design that looks good to the eye can be unreadable to a camera.

Paper, surface and environment

The surface matters as much as the print. Glossy paper reflects light and creates glare that can blind a scanner; matte paper is safer. A code on a curved surface, such as a bottle or a cup, distorts when viewed from an angle, so keep codes on flat areas where possible. Outdoor codes need to survive sun, rain and dirt: laminate them or print them on weatherproof material, and use a high error correction level so the code still reads when part of it is damaged. A code behind glass can reflect the scanner's own light; angle it or move it to avoid the reflection. And remember that a code printed on a moving vehicle is effectively unscannable.

The pre-print test that saves money

Before printing a full run, print one copy at the final size on the final material, and test it the way your audience will use it: from the real distance, in the real lighting, on two different phones. Check that it scans quickly on the first try, not after several attempts. If it is slow or unreliable, make it bigger, increase the contrast, simplify the contents with a shorter URL, or raise the error correction level. A five-minute test now is far cheaper than reprinting a thousand flyers, and it is the single most valuable habit in QR code printing.

Frequently asked questions

What is the smallest a QR code can be?

About 2 centimetres wide for scanning at arm's length. For greater distances, allow roughly 10 centimetres of width per metre of distance.

What resolution should I print a QR code at?

300 dots per inch or better, from a high-resolution file. Our generator downloads a 1024 by 1024 pixel PNG.

Can a QR code be a colour other than black?

Yes, if the contrast stays strong. Dark colours on white usually work; light colours, inverted codes and codes over photos often fail.
