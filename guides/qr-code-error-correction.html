QR Code Error Correction Explained (L, M, Q, H)

Those four letters decide whether your code survives a coffee stain, a logo, or a torn corner. What each level does and when to use it.

Every QR code generator asks you to choose an error correction level — L, M, Q or H — and most people pick one at random. The choice matters more than it looks, because it decides how much damage the code can survive and how dense the pattern becomes. A code with the right level scans reliably in the real world; a code with the wrong level either fails when it gets dirty or is needlessly complex. This guide explains what error correction does, how the four levels differ, and how to choose the right one for each use.

What error correction actually does

A QR code does not just store your data; it also stores redundant copies of it, calculated using a mathematical technique called Reed-Solomon error correction. When a scanner reads the code, it uses those redundant copies to reconstruct any modules that are missing, damaged or hidden — a stain, a crease, a logo in the middle, or a corner that has been torn off. The scanner does not need to see every module; it needs to see enough of them, and the error correction data fills in the rest. That is why a QR code can still scan when a quarter of it is covered, and why a code with a logo in the centre still works.

The four levels, in numbers

Level L, for Low, can reconstruct about 7 percent of the code's data. Level M, for Medium, can reconstruct about 15 percent. Level Q, for Quartile, can reconstruct about 25 percent. Level H, for High, can reconstruct about 30 percent. Higher levels need more space for the redundant data, so the code becomes denser, with more and smaller modules, which makes it slightly harder to scan at small sizes. Level M is the default in most generators because it balances robustness with simplicity. Level L is best when the code must be as small and simple as possible and will stay in perfect condition. Level H is best when the code will be handled roughly, displayed outdoors, or printed with a logo.

When to use each level

Use level L for a code on a screen or a clean print that will be scanned once and never handled — a ticket on a phone, for example. Use level M for most everyday uses: flyers, business cards, menus, posters. Use level Q for codes that will be handled, laminated, or displayed where they may get dirty — a table tent in a restaurant, a code on a product, a badge. Use level H for codes with a logo in the middle, codes printed outdoors, codes on clothing or packaging that will be bent, and codes that must survive rough treatment. The cost of a higher level is a denser code, so pair it with a slightly larger print size to keep scanning easy.

Error correction and logos

The reason a logo can sit in the middle of a QR code is error correction: the modules hidden behind the logo are reconstructed from the redundant data. But the logo is damage, and the level decides how much damage is affordable. A small logo covering 10 percent of the code needs at least level M; a larger logo needs level Q or H. Keep the logo in the centre and away from the three corner position squares, which the scanner needs intact to locate the code. And remember that the logo is not free: a code with a logo and level H is denser than a plain code, so print it a little larger and test it on several phones.

A common misunderstanding

Error correction does not make a code work if the data itself is wrong. If the URL in the code has a typo, no level of error correction will fix it; the scanner will faithfully reconstruct the wrong address. Error correction protects against physical damage to the pattern, not against mistakes in the content. That is why testing matters more than the level: scan the finished code and check that it leads where you intended. Choose level M as your default, H when the code will be abused or branded, and L only when size matters more than robustness — and always test the printed result.

Frequently asked questions

What error correction level should I use?

Level M for most uses. Use H for codes with a logo, outdoor codes, or codes that will be handled roughly. Use L only for small, clean, short-lived codes.

Can a damaged QR code still scan?

Yes, if the damage is within the error correction level — up to 30 percent at level H — and the three corner position squares are intact.

Does a higher error correction level make the code bigger?

It makes the code denser, with more modules. Print a high-level code slightly larger to keep it easy to scan.
