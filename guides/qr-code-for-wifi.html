How to Create a QR Code for Your Wi-Fi Network

Stop spelling out your Wi-Fi password letter by letter. Print a QR code and let guests join with one scan.

Every host knows the ritual: a guest asks for the Wi-Fi password, you recite a string of letters and numbers, they mistype it twice, and you spell it out again, character by character. A Wi-Fi QR code ends all of that. Guests point their phone camera at a printed code and join the network instantly, without seeing or typing the password at all. It is faster, friendlier, and more secure than shouting your password across a room. This guide shows you how to make one, where to put it, and what to watch out for.

How a Wi-Fi QR code works

A Wi-Fi QR code stores your network's details in a standard format that phones understand: the network name, the security type, and the password, written as WIFI:T:WPA;S:YourNetwork;P:YourPassword;;. When a phone scans it, the camera app recognises the format and offers to join the network, filling in the password automatically. The guest never sees the password, never types it, and cannot easily share it with someone else — although a determined person can still read it from their phone's saved networks, so this is convenience, not military security. The format works on modern iPhones and Android phones without any extra app.

Making the code in three steps

First, find your network name and password: the name is usually printed on your router, and the password is on a sticker on the router or in your router's settings. Second, enter them into the Wi-Fi QR tool on this site, choosing the right security type — WPA for almost all modern routers, WEP only for very old ones, and no password only for a genuinely open network. Third, generate the code, scan it with your own phone to check that it connects, and print it. If your network name or password contains a semicolon, comma, colon or backslash, the tool escapes it automatically; if you are writing the format by hand, those characters need a backslash in front of them.

Where to put the code

Print the code on a small card and leave it where guests will naturally look: the coffee table in a holiday rental, the reception desk in a cafe, the meeting room table in an office, or the fridge in a family home. Laminate it if it will be handled often or left near drinks. Make it large enough to scan from a comfortable distance — at least 4 or 5 centimetres wide — and keep the print sharp and high contrast. If you run a business, add a short line of text above it, such as Scan to join our Wi-Fi, so people know what it is. And keep the card away from windows where sunlight can wash out the print.

Security: who can use it, and when to change it

Anyone who scans the code can join your network, so treat a printed Wi-Fi code like a spare key. For a home network, that is usually fine for family and trusted guests. For a business, use a separate guest network with its own password, so visitors never reach your private devices, printers and files. Change the Wi-Fi password — and reprint the code — whenever someone who had access should no longer have it, such as a former tenant, a departed employee, or an ex-partner. Also change it if you suspect the password has been shared widely. A guest network with a changed password every few months is a good balance between hospitality and security.

Troubleshooting: when the code does not connect

If a guest's phone scans the code but does not connect, check the details first: a wrong password or a mistyped network name is the most common cause, so regenerate the code and check every character. Make sure the security type matches your router — choosing WPA when the router uses WEP, or the reverse, will fail. If the network is hidden, tick the hidden-network option when generating the code, because the phone needs to know to look for a network that is not broadcasting. Very old phones may not support Wi-Fi QR codes at all; in that case, the guest will need to type the password manually. And if the code scans but nothing happens, the phone's camera app may need permission to join networks, which can be enabled in its settings.

Frequently asked questions

Will guests see my Wi-Fi password?

No. The phone joins the network automatically without showing the password on screen, though a tech-savvy guest could find it in their saved networks.

Does a Wi-Fi QR code work on iPhone and Android?

Yes. Both support the standard Wi-Fi QR format with their built-in camera apps — no extra app needed.

What if I change my Wi-Fi password?

The old code stops working. Generate a new code with the new password and reprint it.
