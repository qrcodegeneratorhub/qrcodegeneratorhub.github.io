QR Codes in Marketing: Flyers, Posters and Packaging

A QR code turns a poster into a doorway. How marketers use codes on print, and how to measure whether they are working.

Print marketing has a perennial problem: a flyer or a poster can show a message, but it cannot easily turn a reader into a customer. A QR code closes that gap. One scan takes the reader from the poster to a product page, a sign-up form, a video or a discount, without typing a long address. The code costs nothing to add, and it turns every printed surface into a measurable channel. But most marketing QR codes fail, because they are too small, unexplained, or linked to a page that was never designed for a phone. This guide covers the placements that work and the measurement that proves it.

Flyers and posters: the scan must be worth it

A QR code on a flyer works when the scan offers something the reader wants right now: a discount, a menu, a booking form, a video, or more information about the thing in the poster. It fails when it links to a generic homepage, because the reader could have found that by searching. Give the code a clear call to action — Scan for 10% off, Scan to watch the trailer, Scan to book — and make the destination deliver on that promise immediately. Make the code large enough to scan from the distance people stand at: a poster on a wall needs a much bigger code than a flyer held in the hand. And always test the code in place, from the real viewing distance, before printing a thousand copies.

Packaging: the code that keeps selling

Packaging is the most valuable surface for a QR code, because the customer is holding the product at home, with time and a phone in hand. A code on a food packet can link to recipes, a code on a cosmetics box to a tutorial, a code on an electronics box to a setup guide or a warranty registration. These uses build loyalty and reduce support calls, because the customer gets help without searching. Use a dynamic code for packaging if the destination may change over the product's lifetime, and make sure the code survives handling: print it on a flat, light-coloured area, not across a fold or a seam, and test it after the packaging has been through the normal production process.

Direct mail and catalogues

A QR code in a catalogue or a direct mail piece lets the reader jump straight to the product page, which is far more effective than asking them to type a product code into a website. Give each product its own code, or at least each page its own code, so you can tell which products are attracting attention. Keep the destination mobile-friendly and fast, because the reader is on a phone. And do not use a QR code as a substitute for the information the reader needs to decide: the price, the size, and the key features should be in print, with the code offering the next step — ordering, more photos, or a video — rather than the basic facts.

Events, exhibitions and out-of-home

At an exhibition, a QR code on a stand lets a visitor save your details, download a brochure, or enter a competition without carrying paper. On a billboard or a bus shelter, the code must be enormous — big enough to scan from several metres away — and the destination must be simple, because nobody will stand in the street filling in a long form. On a vehicle, a code is usually a waste: the vehicle is moving, and nobody can scan it safely. The rule for out-of-home is to ask whether a person standing there, phone in hand, can scan the code comfortably and would want to. If either answer is no, leave the code off.

Measuring marketing QR codes

A static QR code has no built-in analytics, so build measurement into the destination: give each placement its own web address or tracking tag, so your website statistics show how many visits each code produced. Compare codes against each other — the flyer code against the poster code, the packaging code against the receipt code — and move budget toward the placements that work. Count conversions, not just scans: a code that is scanned a thousand times but produces no orders is less valuable than one scanned a hundred times that produces ten. And survey a few customers: ask whether they scanned the code, and if not, why. The answers will usually point to size, labelling or destination, all of which are cheap to fix.

Frequently asked questions

Should a marketing QR code link to my homepage?

Usually not. Link to the specific offer, product or form the advert promises, so the scan delivers on the promise immediately.

How big should a QR code on a poster be?

Big enough to scan from the distance people stand at — roughly 10 centimetres of width for every metre of viewing distance.

Can I measure how many people scan my marketing codes?

Yes, by giving each code its own destination address and counting visits to each one in your website statistics.
