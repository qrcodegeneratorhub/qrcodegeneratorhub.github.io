QR Code Design Tips: Colours, Logos and Branding

A QR code can look good and still scan. The design rules that keep a branded code readable on every phone.

A plain black-and-white QR code works perfectly, but it is not very attractive, and businesses understandably want the code to match their brand. The good news is that a QR code can be coloured, branded and even carry a logo — as long as the design respects how scanners read the pattern. The bad news is that many beautifully designed codes do not scan at all, because the designer optimised for the eye and ignored the camera. These tips show you how to have both: a code that looks like your brand and scans like a plain one.

Contrast first, brand second

A scanner reads a QR code by distinguishing dark modules from light ones, so contrast is the one rule you cannot break. Dark modules on a light background work; light modules on a dark background often fail, because many scanners assume the code is dark on light. Keep the contrast strong: a dark blue, dark green or black code on white is safe, while a pale yellow code on white is not. If your brand colour is light, use it around the code — in the border, the label, or the background of the poster — and keep the code itself dark. Test every coloured code on two different phones before printing, because a colour combination that looks clear to you can be marginal to a camera.

Adding a logo without breaking the code

A small logo in the centre of a QR code is the most popular branding trick, and it works because QR codes include error correction: the scanner can reconstruct the modules hidden behind the logo. But there are limits. Keep the logo small — no more than about 20 percent of the code's width — and keep it in the centre, well away from the three large position squares in the corners, which the scanner needs to find the code. Use a high error correction level, H if possible, because it gives the scanner the most spare data to work with. And test the result on several phones, because a logo that works on one phone may fail on another with a weaker camera.

Shapes, gradients and rounded corners

Designers like to round the corners of the modules, use a gradient, or replace the squares with circles. These changes are usually safe in moderation, because scanners read the centre of each module rather than its edges, but they reduce the margin for error. A gradient that fades from dark to light across the code can make one side unscannable. Rounded modules are generally fine. A code with a custom shape — a heart, a logo outline — is risky, because it can distort the position squares. As a rule, keep the three corner squares square and dark, keep the modules uniform, and treat decorative changes as a garnish, not a redesign. If in doubt, print a plain version and a designed version and compare their scan speed.

Frames, labels and calls to action

The frame around a QR code is where branding belongs. A coloured frame with a short instruction — Scan to see the menu, Scan for 10% off — tells people what the code does and why they should scan it, which a bare code never does. The frame also provides the quiet zone, the blank margin the scanner needs around the code, so make sure the frame does not crowd the code itself. Put your logo in the frame rather than in the code when you can, because the frame has no effect on scanning at all. A well-labelled code in a branded frame looks professional, scans reliably, and gets scanned far more often than a bare code.

Testing a designed code properly

Test a designed code harder than a plain one, because it has less margin for error. Print it at the final size, on the final material, and scan it from the real distance, in the real lighting, on an iPhone and an Android phone, including an older phone if you can. Time the scan: a good code scans in under two seconds, while a marginal one takes several attempts. If it is slow, increase the size, raise the error correction level, shrink the logo, or strengthen the contrast. A designed code that scans slowly is worse than a plain code that scans instantly, because every failed scan is a customer who gives up. Design for the scanner first and the eye second.

Frequently asked questions

Can I put my logo in a QR code?

Yes, if it is small, centred, and you use a high error correction level. Test it on several phones before printing.

What colours work for QR codes?

Dark colours on a white background. Avoid light colours, inverted codes and codes printed over busy images.

Does a fancy QR code still scan reliably?

It can, if the contrast stays strong and the corner squares are untouched. Always test the final design before printing.
